# EE-CAD-Agents

**Electrical drafting. DWG automation. Agent-assisted workflows.**

EE-CAD-Agents is being developed to turn repetitive electrical CAD work into controlled, repeatable drawing operations. The focus is practical: work with existing DWG projects, preserve drawing conventions, and make changes that can be inspected.

## What we're building

- **Drawing inspection** — identify devices, layers, routes and selected work areas.
- **Batch drafting** — apply repeatable operations across equivalent drawing locations.
- **Circuit editing** — assist with cable routes, socket connections and loop-in/loop-out conversion.
- **Dimensions and annotation** — place coordinated dimensions and labels using drawing-specific rules.
- **Validation** — check connectivity, spacing and unintended changes before delivery.

These are development areas, not a claim of universal CAD compatibility or unattended design correctness.

## Current status

**In development · No public release yet**

The engineering prototype is under active testing. Complex drawing interpretation and final electrical design decisions still require review. There is currently no public installer, API, production release or published performance guarantee.
